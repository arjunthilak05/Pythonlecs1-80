Understanding Different Kinds of Information in Python!

What are Data Types?

In Python, different types of information need to be stored differently. Just like in real life, we treat numbers differently from words! Data types tell Python what kind of information we're working with.

💡Key Idea

A data type is like a category that tells Python what kind of value you're storing and what you can do with it!

📝
String (str)

Text and words

name = "Alex" message = "Hello!"

Always use quotes: "text" or 'text'

🔢
Integer (int)

Whole numbers

age = 12 score = 100

No decimal points, no quotes

🎯
Float (float)

Decimal numbers

price = 19.99 pi = 3.14

Has a decimal point

✅
Boolean (bool)

True or False

is_student = True game_over = False

Only two values: True or False

Numbers - Integers and Floats

# Integers (whole numbers) age = 15 lives = 3 # Floats (decimal numbers) price = 9.99 temperature = 98.6 # Math with numbers total = 10 + 5 # 15 result = 20 - 3 # 17 product = 4 * 5 # 20 division = 10 / 2 # 5.0 (becomes float!)

💡Fun Fact!

When you divide numbers, Python always gives you a float (even if the answer is a whole number)!

Booleans - True or False
