⚙️ Part 0 — Compiler vs Interpreter

How does code actually run?

You write code in a human-readable language like Python or C++. But your computer only understands machine code — pure 0s and 1s. Something has to translate your code into that. That "something" is either a Compiler or an Interpreter.

📦 Compiler

Reads your entire program at once, translates all of it into machine code, then produces a separate executable file you can run any time — even without the original code.

  • Translates everything before running
  • Reports all errors together at the end
  • Runs very fast once compiled
  • Creates a standalone .exe file
C C++ Rust Go
🔍 Interpreter

Reads your code one line at a time and runs each line immediately — no separate file is created. It needs to be present every time you run the program.

  • Translates & runs line by line
  • Stops and shows an error the moment it hits one
  • Slightly slower than compiled code
  • Easier to test and debug quickly
Python 🐍 JavaScript Ruby

🎬 Analogy: Movie Subtitle vs Live Translator

Think of it this way:

📦 Compiler = Subtitles

The entire film is translated into subtitles before the movie even starts. Once done, anyone can watch it — fast, no delay. But if there's a typo in the subtitle, you only find out when the whole translation is finished.

🔍 Interpreter = Live Translator

A translator sits next to you and translates each sentence as the actor speaks it. If the actor says something wrong, the translator stops immediately and tells you right there and then.

⚡ See it in action — how each handles an error

Say you have a 5-line program with a mistake on line 3:

📦 COMPILER (e.g. C++)
Reads ALL 5 lines first...
↓
Translates entire program
↓
ERROR on line 3! (found after full scan)
↓
Nothing runs until fixed
🔍 INTERPRETER (e.g. Python)
✅ Runs line 1 → output
↓
✅ Runs line 2 → output
↓
❌ STOPS at line 3 immediately
↓
Lines 4 & 5 never run
💡 Python is an interpreter — that's why you can open the Python shell, type one line, and see the result instantly. It reads and runs your code one line at a time, right away!
🐍 Part 1 — What is Python?

Why Python?

Python is a programming language — a way to give instructions to a computer in human-readable text. It was created in 1991 and named after Monty Python (a British comedy show!). Today it's used by:

  • 🤖 AI researchers at Google & OpenAI
  • 🎮 Game developers (some tools use Python)
  • 📊 Data scientists who analyze huge datasets
  • 🌐 Web developers building backends
💡 Python reads almost like plain English — that's why it's the #1 language taught to beginners worldwide!

Your First Python Code

In Python, print() shows text on the screen. Every programmer writes this first:

print("Hello, World!") # shows: Hello, World! print("I am learning Python!") x = 5 + 3 print(x) # shows: 8

The computer reads each line top to bottom, one at a time — just like reading a recipe step by step.

🌿 Part 2 — GitHub & Branches

What is GitHub?

Git is a tool that saves snapshots of your code over time — like an "undo history" that never expires. GitHub is a website where you store your code online so you can:

  • 🌍 Access your code from anywhere
  • 👯 Work on the same project with teammates
  • 📜 See every change ever made, and roll back if needed
  • 🌟 Show your projects to the world (like a coding portfolio!)
💡 GitHub hosts over 100 million projects. Every big tech company — Google, Meta, Microsoft — uses Git every single day!

What are Branches?

Imagine your code is a tree 🌳. The main branch is the trunk — the working, finished version. When you want to add a new feature, you create a branch (like a tree branch) so you can experiment without breaking the main code.

main ●──────────●──────────────────────●──> (v1.0 live) \ / feature ●────●────●──/ <-- (add login page) main ●────────────────────────●────●──> \ hotfix ●──<-- (fix urgent bug)

Key commands:

git init # start a new repository git branch feature/login # create a new branch git checkout feature/login # switch to that branch git commit -m "Add login" # save your changes git merge feature/login # merge back into main
📓 Part 3 — Google Colab

What is Google Colab?

Google Colaboratory (Colab) is a free, online Python environment that runs in your browser — no installation needed! It's a Jupyter Notebook, which means your code lives in little boxes called cells.

  • ☁️ Runs entirely in your browser — works on any computer
  • 🔋 Free GPU/TPU access for AI/ML projects
  • 🤝 Share notebooks like Google Docs
  • 💾 Auto-saves to your Google Drive
💡 Go to colab.research.google.com — sign in with Google and you're coding Python in 10 seconds!

How Notebooks Work

A notebook has two types of cells. You run each cell by pressing Shift + Enter or clicking the ▶ button:
