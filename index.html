🔗String Concatenation - Joining Text

Concatenation means joining strings together using the + operator!

💡Key Idea

You can add strings together just like building with LEGO blocks! Each piece connects to make something bigger.

# Simple concatenation first = "Hello" second = "World" result = first + " " + second print(result) # Hello World # Building sentences name = "Alex" age = "12" message = "My name is " + name + " and I am " + age print(message) # My name is Alex and I am 12

🛠️String Methods - Built-in Superpowers!

Strings come with built-in functions called methods that can transform text!

.upper()

Converts all letters to UPPERCASE

text = "hello" print(text.upper()) # HELLO
.lower()

Converts all letters to lowercase

text = "HELLO" print(text.lower()) # hello
.replace(old, new)

Replaces parts of a string with something else

text = "I love cats" print(text.replace("cats", "dogs")) # I love dogs
.strip()

Removes extra spaces from beginning and end

text = " hello " print(text.strip()) # hello

✨F-Strings - The Modern Way!

F-strings (formatted strings) are the easiest way to put variables inside strings!

💡Key Idea

Put an f before the quote and use {} to insert variables directly!

# Old way (concatenation) name = "Alex" age = 12 message = "My name is " + name + " and I am " + str(age) # New way (f-string) - Much easier! message = f"My name is {name} and I am {age}" print(message) # My name is Alex and I am 12 # You can even do math inside f-strings! score = 95 print(f"Next level needs {score + 5} points!")
