🚀 Lecture 1: Welcome to Programming!

🤖 What is Programming?

Programming is like giving instructions to a robot! Imagine you have a robot friend who is very smart but only understands specific commands. You need to tell them exactly what to do, step by step.

For example, if you want the robot to make a sandwich, you can't just say "make a sandwich." You need to say:

  • Pick up the bread
  • Open the jar of peanut butter
  • Spread peanut butter on the bread
  • Put two slices together

That's exactly what programming is! We write instructions (called code) that tell the computer exactly what to do!

🎉 Your First Program: Hello, World!

The first program every programmer writes is "Hello, World!" It's a tradition! This program tells the computer to display a message on the screen.

In Python, we use the print() command to display text. Here's how it looks:

print("Hello, World!")

When you run this code, the computer will show: Hello, World!

📖 How Computers Read Code Line by Line

Computers are very obedient but not very smart. They read your code one line at a time, from top to bottom, just like you read a book!

Let's look at an example:

print("First, I say hello!")
print("Then, I say goodbye!")
print("And finally, I'm done!")

The computer will:

  1. Read line 1 and print "First, I say hello!"
  2. Then read line 2 and print "Then, I say goodbye!"
  3. Finally read line 3 and print "And finally, I'm done!"

💡 Remember: The order matters! The computer does exactly what you tell it, in the order you tell it.
