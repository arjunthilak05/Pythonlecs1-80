🔄While Loop Fundamentals

A while loop repeats code as long as a condition is True. When the condition becomes False, the loop stops!

# Basic while loop structure while condition: # Code to repeat # This runs over and over while condition is True # Example 1: Count from 1 to 5 count = 1 while count <= 5: print(count) count = count + 1 # Important: update the variable! # Output: 1, 2, 3, 4, 5 # Example 2: Ask until correct password password = "" while password != "python": password = input("Enter password: ") print("Access granted!") # Example 3: Sum numbers until 0 total = 0 num = int(input("Enter number (0 to stop): ")) while num != 0: total += num num = int(input("Enter number (0 to stop): ")) print(f"Total: {total}")

⚠️Critical: Avoid Infinite Loops!

If your condition NEVER becomes False, the loop will run FOREVER!

# BAD - Infinite loop! Don't run this! count = 1 while count <= 5: print(count) # Forgot to update count! Will print 1 forever! # GOOD - Loop will end count = 1 while count <= 5: print(count) count += 1 # Update variable!

Always make sure:

  • The condition can become False
  • You update variables in the loop
  • There's a way to exit

🛑Break Statement

The break statement lets you exit a loop immediately, even if the condition is still True!

# Break - exit loop immediately while True: # Infinite loop on purpose! name = input("Enter name (or 'quit'): ") if name == "quit": break # Exit the loop! print(f"Hello, {name}!") print("Goodbye!") # Example 2: Find a number numbers = [5, 12, 8, 3, 15, 7] target = 8 index = 0 while index < len(numbers): if numbers[index] == target: print(f"Found {target} at index {index}!") break # Stop searching! index += 1 # Example 3: Limited attempts attempts = 0 max_attempts = 3 while True: password = input("Enter password: ") attempts += 1 if password == "secret": print("Access granted!") break if attempts >= max_attempts: print("Too many attempts!") break print(f"Wrong! {max_attempts - attempts} attempts left")

💡When to Use Break

  • 🎯 Found what you're searching for
  • ❌ Error condition encountered
  • 🔢 Reached maximum attempts
  • ✅ Task completed successfully
  • 🚪 User wants to exit/quit

⏭️Continue Statement

The continue statement skips the rest of the current iteration and goes to the next one!

# Continue - skip to next iteration count = 0 while count < 10: count += 1 if count % 2 == 0: continue # Skip even numbers! print(count) # Only prints odd numbers: 1, 3, 5, 7, 9 # Example 2: Skip negative numbers numbers = [5, -2, 8, -1, 3, -7, 12] index = 0 while index < len(numbers): num = numbers[index] index += 1 if num < 0: continue # Skip negative numbers print(num) # Prints: 5, 8, 3, 12 # Example 3: Skip invalid input valid_count = 0 while valid_count < 3: age = int(input("Enter age: ")) if age < 0 or age > 120: print("Invalid age! Try again.") continue # Don't count this one print(f"Valid age: {age}") valid_count += 1

📊Break vs Continue

Statement What It Does Use When
break Exits the entire loop Done with the loop, found answer, error
continue Skips to next iteration Skip this item, but keep looping

⚠️Common Mistakes to Avoid:

  • Forgetting to update loop variables (infinite loop!)
  • Wrong condition (loop never runs or never stops)
  • Missing colon (:) after while statement
  • Wrong indentation of loop body
  • Using = instead of == in condition
