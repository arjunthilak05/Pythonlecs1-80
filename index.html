➕Basic Arithmetic Operators

These are the fundamental math operations you use every day!

+
Addition

Adds two numbers together

result = 5 + 3 print(result) # Output: 8 total = 100 + 50 + 25 print(total) # Output: 175
-
Subtraction

Subtracts one number from another

result = 10 - 4 print(result) # Output: 6 balance = 1000 - 250 print(balance) # Output: 750
*
Multiplication

Multiplies two numbers

result = 6 * 7 print(result) # Output: 42 total_price = 5 * 12.99 # 5 items at $12.99 print(total_price) # Output: 64.95
/
Division

Divides one number by another

result = 15 / 3 print(result) # Output: 5.0
⚠️ Important: Division in Python ALWAYS returns a float (decimal), even if the answer is a whole number!

⚡Advanced Operators

Python has special operators for more complex calculations!

**
Exponent (Power)

Raises a number to a power (like x² or x³)

result = 2 ** 3 # 2 × 2 × 2 = 2³ print(result) # Output: 8 squared = 5 ** 2 # 5 × 5 = 5² print(squared) # Output: 25 cubed = 3 ** 3 # 3 × 3 × 3 = 3³ print(cubed) # Output: 27
%
Modulo (Remainder)

Returns the remainder after division

result = 10 % 3 print(result) # Output: 1 (10 ÷ 3 = 3 remainder 1) even_check = 8 % 2 print(even_check) # Output: 0 (8 is even) odd_check = 7 % 2 print(odd_check) # Output: 1 (7 is odd)
💡 Use Case: Modulo is super useful for checking if a number is even or odd! If number % 2 == 0, it's even!
//
Floor Division

Divides and rounds down to the nearest whole number

result = 10 // 3 print(result) # Output: 3 (not 3.33...) result = 17 // 5 print(result) # Output: 3 (not 3.4)

📋Order of Operations (PEMDAS)

When you have multiple operations in one expression, Python follows a specific order - just like in math class!

PEMDAS / BODMAS

1. Parentheses / Brackets: ( )
2. Exponents / Orders: **
3. Multiplication & Division: * / // %
4. Addition & Subtraction: + -
# Example 1: Without parentheses result = 2 + 3 * 4 print(result) # Output: 14 (not 20!) # Why? Multiplication happens first: 2 + (3 * 4) = 2 + 12 = 14 # Example 2: With parentheses result = (2 + 3) * 4 print(result) # Output: 20 # Parentheses first: (2 + 3) * 4 = 5 * 4 = 20 # Example 3: Complex expression result = 10 + 2 ** 3 * 5 print(result) # Output: 50 # Step by step: # 1. Exponent first: 2**3 = 8 # 2. Then multiplication: 8*5 = 40 # 3. Finally addition: 10+40 = 50

⚠️Common Mistake!

Students often forget that multiplication and division happen BEFORE addition and subtraction!

# Wrong thinking: 5 + 2 * 3 = 21 # ❌ WRONG! # Correct: 5 + 2 * 3 = 11 # ✅ CORRECT! # Because: 5 + (2*3) = 5 + 6 = 11
