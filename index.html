💬What is User Input?

Until now, all our data was hardcoded (we wrote it in the program). But real programs need to interact with users! The input() function lets users type information into your program.

💡Key Idea

input() pauses your program and waits for the user to type something and press Enter. Whatever they type becomes a string!

# Basic input example name = input("What is your name? ") print("Hello", name) # Example output: # What is your name? Alex # Hello Alex

🎯Try it yourself!

Type your name and see how input() works:

>>> name = input("What is your name? ")
>>> print("Hello", name)

⚠️Important: input() Always Returns Strings!

# This looks like a number, but it's a string! age = input("Enter your age: ") print(type(age)) # <class 'str'> # This won't work! next_year = age + 1 # ERROR! Can't add string and number

🚨The Problem

Even if the user types "15", Python treats it as the string "15", not the number 15!

❌ Wrong Way

age = input("Age: ") next = age + 1 # TypeError!

✅ Right Way

age = int(input("Age: ")) next = age + 1 # Works!

🔄Converting Input Types

To do math with user input, we need to convert the string to a number!

# Convert to integer (whole number) age = int(input("Enter your age: ")) print("Next year you'll be", age + 1) # Convert to float (decimal number) price = float(input("Enter price: ")) tax = price * 0.1 print("Tax:", tax) # Keep as string (for text) name = input("Enter your name: ") print("Welcome", name)
