🚦Part 1: Simple If Statements

The if statement is the most basic way to make decisions. If a condition is True, the code inside runs. If False, it's skipped!

# Basic if statement structure if condition: # This code runs ONLY if condition is True print("Condition is True!") # Example 1: Simple age check age = 16 if age >= 13: print("You are a teenager!") # Example 2: Password check password = "python123" if password == "python123": print("Access granted!") # Example 3: Score check score = 95 if score > 90: print("Excellent work!")

⚠️CRITICAL: Indentation!

Python uses indentation (spaces at the beginning of lines) to know what code belongs to the if statement!

if age >= 18: ← Colon here!
print("Adult") ← 4 spaces indent!
print("Can vote") ← Same indent!
print("Program continues") ← Back to start

Remember:

  • Always use a colon (:) after the condition
  • Indent with 4 spaces (or 1 Tab)
  • All indented lines belong to the if

What if we want to do something when the condition is False? Use else!

# If-Else structure if condition: # Runs if True print("Condition is True") else: # Runs if False print("Condition is False") # Example 1: Age verification age = 12 if age >= 18: print("You can vote!") else: print("You cannot vote yet.") # Example 2: Password check password = input("Enter password: ") if password == "secret123": print("✅ Access granted!") else: print("❌ Access denied!") # Example 3: Even or Odd number = 7 if number % 2 == 0: print("Even number") else: print("Odd number")

🔀Part 3: If-Elif-Else (Multiple Paths)

What if we have MORE than two options? Use elif (else if) to check multiple conditions!

💡When to Use Elif

Use elif when you have multiple exclusive conditions (only one can be true):

  • Grade ranges (A, B, C, D, F)
  • Age groups (child, teen, adult, senior)
  • Temperature ranges (cold, warm, hot)
  • Price tiers (budget, standard, premium)
# If-Elif-Else structure if condition1: # Runs if condition1 is True print("First condition") elif condition2: # Runs if condition1 is False AND condition2 is True print("Second condition") elif condition3: # Runs if previous conditions are False AND condition3 is True print("Third condition") else: # Runs if ALL conditions are False print("None of the above") # Example 1: Grade system score = 85 if score >= 90: print("Grade: A") elif score >= 80: print("Grade: B") elif score >= 70: print("Grade: C") elif score >= 60: print("Grade: D") else: print("Grade: F") # Example 2: Age groups age = 25 if age < 13: print("Child") elif age < 20: print("Teenager") elif age < 60: print("Adult") else: print("Senior")

⚠️Important: Order Matters!

Python checks conditions from TOP to BOTTOM and stops at the FIRST True condition!

❌ Wrong Order

score = 95 if score >= 60: print("D") # Always runs first! elif score >= 90: print("A") # Never reached!

✅ Correct Order

score = 95 if score >= 90: print("A") # Checks highest first! elif score >= 60: print("D") # Checks lower values

🎯Part 4: Nested Conditionals

You can put if statements INSIDE other if statements! This is called nesting.

# Nested if statements age = 20 has_license = True if age >= 18: print("You are old enough to drive") if has_license: print("You can drive!") else: print("But you need a license first") else: print("You are too young to drive") # Example 2: Login system with multiple checks username = "admin" password = "pass123" is_active = True if username == "admin": if password == "pass123": if is_active: print("✅ Login successful!") else: print("❌ Account is inactive") else: print("❌ Wrong password") else: print("❌ User not found")

Notice the Indentation Levels:

if outer_condition: ← Level 1
if inner_condition: ← Level 2 (nested)
print("Both true") ← Level 3 (inside nested)

⚠️Common Mistakes to Avoid:

  • Forgetting the colon (:) after if/elif/else
  • Wrong indentation (use 4 spaces)
  • Using = instead of == for comparison
  • Wrong order in elif chains (check highest values first)
  • Missing else when you need a default case
