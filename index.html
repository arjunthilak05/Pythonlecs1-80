📦What is a List?

A list is a collection that can store multiple values in a single variable. Think of it as a container with numbered slots!

🎯List Characteristics

  • 📝 Ordered: Items stay in the order you add them
  • 🔢 Indexed: Each item has a position number (starting from 0)
  • ✏️ Mutable: You can change, add, or remove items
  • 🎨 Mixed types: Can store different data types
  • 🔁 Duplicates allowed: Can have the same value multiple times
# Creating lists fruits = ["apple", "banana", "cherry"] numbers = [10, 20, 30, 40, 50] mixed = ["hello", 42, True, 3.14] empty = [] # Print lists print(fruits) # ['apple', 'banana', 'cherry'] print(numbers) # [10, 20, 30, 40, 50]

⚠️Important: Index Starts at 0!

In Python, the first item is at index 0, not 1!

  • Index 0 → First item
  • Index 1 → Second item
  • Index 2 → Third item
  • And so on...

🔍Accessing List Items

Use square brackets [ ] with the index number to access items!

# Create a list fruits = ["apple", "banana", "cherry", "date", "elderberry"] # Access by index (starts at 0) print(fruits[0]) # apple (first item) print(fruits[1]) # banana (second item) print(fruits[2]) # cherry (third item) # Negative indexing (from the end) print(fruits[-1]) # elderberry (last item) print(fruits[-2]) # date (second from end) # Get list length length = len(fruits) print(length) # 5 # Change an item fruits[1] = "blueberry" print(fruits) # ['apple', 'blueberry', 'cherry', 'date', 'elderberry']

🛠️List Methods

Lists come with built-in methods to add, remove, and modify items!

.append(item)

Purpose: Add an item to the END of the list

# append() - add to end fruits = ["apple", "banana"] fruits.append("cherry") print(fruits) # ['apple', 'banana', 'cherry'] # Add multiple items fruits.append("date") fruits.append("elderberry") print(fruits) # ['apple', 'banana', 'cherry', 'date', 'elderberry']
.insert(index, item)

Purpose: Add an item at a SPECIFIC position

# insert() - add at specific index fruits = ["apple", "cherry"] fruits.insert(1, "banana") # Insert at index 1 print(fruits) # ['apple', 'banana', 'cherry'] # Insert at beginning fruits.insert(0, "apricot") print(fruits) # ['apricot', 'apple', 'banana', 'cherry']
.remove(item)

Purpose: Remove the FIRST occurrence of an item (by value)

# remove() - remove by value fruits = ["apple", "banana", "cherry", "banana"] fruits.remove("banana") # Removes first 'banana' print(fruits) # ['apple', 'cherry', 'banana'] # Error if item doesn't exist! # fruits.remove("mango") # ValueError!
.pop(index)

Purpose: Remove and RETURN an item at an index (default: last item)

# pop() - remove by index fruits = ["apple", "banana", "cherry"] # Remove last item (default) last = fruits.pop() print(last) # cherry print(fruits) # ['apple', 'banana'] # Remove at specific index first = fruits.pop(0) print(first) # apple print(fruits) # ['banana']

📊Quick Method Comparison

Method Action Returns
append(item) Add to end None
insert(i, item) Add at index i None
remove(item) Remove by value None
pop(i) Remove at index i Removed item

⚠️Common Mistakes to Avoid:

  • Starting index at 1 instead of 0
  • Using remove() with index instead of value
  • Forgetting that pop() returns the removed item
  • Trying to access index out of range
  • Confusing insert(index, item) parameter order
