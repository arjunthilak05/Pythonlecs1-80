✅❌Boolean Values: True and False

Before we learn comparison operators, we need to understand Boolean values!

💡What is a Boolean?

A Boolean is a data type that can only be True or False. That's it - just two possible values!

True

✅

Yes, correct, 1, on

is_student = True has_permission = True

False

❌

No, incorrect, 0, off

is_admin = False game_over = False
# Creating Boolean variables is_raining = True is_sunny = False # Print Boolean values print(is_raining) # Output: True print(is_sunny) # Output: False # Check the type print(type(is_raining)) # <class 'bool'>

⚠️Important Rules!

  • Capital Letters: True and False - NOT true or false
  • No Quotes: True not "True" (that's a string!)
  • Only Two Values: Nothing else - just True or False

⚖️The Six Comparison Operators

Comparison operators compare two values and return True or False!

==
Equal To

Checks if two values are exactly the same

age = 15 result = age == 15 print(result) # True name = "Alex" print(name == "Bob") # False
⚠️ Common Mistake: == (comparison) vs = (assignment)
x = 5 → Assigns 5 to x
x == 5 → Checks if x equals 5
!=
Not Equal To

Checks if two values are different

score = 85 print(score != 100) # True (85 is not 100) print(score != 85) # False (85 equals 85) status = "active" print(status != "inactive") # True
>
Greater Than

Checks if left value is bigger than right value

score = 95 print(score > 90) # True (95 is greater than 90) print(score > 100) # False (95 is not greater than 100) print(score > 95) # False (95 is not greater than 95)
<
Less Than

Checks if left value is smaller than right value

age = 12 print(age < 18) # True (12 is less than 18) print(age < 10) # False (12 is not less than 10) print(age < 12) # False (12 is not less than 12)
>=
Greater Than or Equal To

Checks if left value is bigger than OR equal to right value

score = 100 print(score >= 90) # True (100 is greater than 90) print(score >= 100) # True (100 equals 100) print(score >= 101) # False (100 is not >= 101)
<=
Less Than or Equal To

Checks if left value is smaller than OR equal to right value

age = 13 print(age <= 18) # True (13 is less than 18) print(age <= 13) # True (13 equals 13) print(age <= 12) # False (13 is not <= 12)
