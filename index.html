➰For Loop Fundamentals

A for loop iterates through each item in a sequence (list, string, etc.) automatically!

# Basic for loop structure for variable in sequence: # Code to repeat for each item # Example 1: Loop through a list fruits = ["apple", "banana", "cherry"] for fruit in fruits: print(fruit) # Output: # apple # banana # cherry # Example 2: Loop through a string word = "Python" for letter in word: print(letter) # Output: P, y, t, h, o, n (each on new line) # Example 3: Calculate sum numbers = [10, 20, 30, 40, 50] total = 0 for num in numbers: total += num print(f"Total: {total}") # Total: 150

💡How For Loops Work

Python automatically:

  1. Takes the first item from the sequence
  2. Assigns it to the variable
  3. Runs the code block
  4. Goes to the next item
  5. Repeats until all items are done

🔢The range() Function

The range() function generates a sequence of numbers - perfect for counting!

# range() has three forms: # 1. range(stop) - from 0 to stop-1 for i in range(5): print(i) # Prints: 0, 1, 2, 3, 4 # 2. range(start, stop) - from start to stop-1 for i in range(1, 6): print(i) # Prints: 1, 2, 3, 4, 5 # 3. range(start, stop, step) - with custom step for i in range(0, 10, 2): print(i) # Prints: 0, 2, 4, 6, 8 # Count backwards with negative step for i in range(5, 0, -1): print(i) # Prints: 5, 4, 3, 2, 1 # Example: Print squares for i in range(1, 6): print(f"{i} squared is {i**2}") # Example: Access list by index fruits = ["apple", "banana", "cherry"] for i in range(len(fruits)): print(f"Index {i}: {fruits[i]}")

⚠️Important: Stop is Exclusive!

range(5) gives you 0, 1, 2, 3, 4 - NOT including 5!

Think: "I want 5 numbers starting from 0" or "Count from 1 to 10? Use range(1, 11)"

📊The enumerate() Function

The enumerate() function gives you both the index AND the value - best of both worlds!

# Without enumerate - manual indexing fruits = ["apple", "banana", "cherry"] for i in range(len(fruits)): print(f"{i}: {fruits[i]}") # With enumerate - much cleaner! for index, fruit in enumerate(fruits): print(f"{index}: {fruit}") # Output: # 0: apple # 1: banana # 2: cherry # Start counting from 1 instead of 0 for position, fruit in enumerate(fruits, start=1): print(f"{position}. {fruit}") # Output: # 1. apple # 2. banana # 3. cherry # Example: Find item position students = ["Alice", "Bob", "Charlie", "Diana"] for rank, student in enumerate(students, start=1): print(f"Rank {rank}: {student}") # Example: Modify list with index scores = [85, 90, 78, 92] for i, score in enumerate(scores): if score > 80: print(f"Student {i+1} passed with {score}")

💡Why Use enumerate()?

  • ✅ Get both index and value in one line
  • ✅ Cleaner code than range(len())
  • ✅ Can customize starting number
  • ✅ More Pythonic and readable

⚖️For Loops vs While Loops

Both repeat code, but when should you use each?

Feature For Loop While Loop
Best For Known iterations, sequences Unknown iterations, conditions
Use When Process each item in list/string Loop until condition changes
Example Print all names in a list Ask until correct password
Counter Automatic (built-in) Manual (you manage it)
Infinite Risk Very low (auto-stops) Higher (forget to update)
# Same task with both loops # FOR LOOP - cleaner for known sequences for i in range(1, 6): print(i) # WHILE LOOP - more setup needed i = 1 while i <= 5: print(i) i += 1 # FOR is better when you know the count! # WHILE is better when you don't!

⚠️Common Mistakes to Avoid:

  • Forgetting that range(5) stops at 4, not 5
  • Using wrong loop (for when while needed, or vice versa)
  • Missing colon (:) after for statement
  • Wrong indentation of loop body
  • Trying to modify list while looping through it
