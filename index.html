🤝The AND Operator

The and operator returns True only if BOTH conditions are True. If even one is False, the whole thing is False!

and
Logical AND

Both conditions must be True

# Basic AND syntax if condition1 and condition2: print("Both are True!") # Example 1: Login check username = "admin" password = "pass123" if username == "admin" and password == "pass123": print("✅ Login successful!") # Example 2: Age and license check age = 20 has_license = True if age >= 18 and has_license: print("You can drive!") # Example 3: Grade requirements score = 85 attendance = 95 if score >= 80 and attendance >= 90: print("Pass with honors!")

🔀The OR Operator

The or operator returns True if AT LEAST ONE condition is True. Only False if ALL are False!

or
Logical OR

At least one condition must be True

# Basic OR syntax if condition1 or condition2: print("At least one is True!") # Example 1: Weekend check day = "Saturday" if day == "Saturday" or day == "Sunday": print("It's the weekend!") # Example 2: Discount eligibility is_student = True is_senior = False if is_student or is_senior: print("You get a discount!") # Example 3: Access permission is_admin = False is_owner = True has_key = False if is_admin or is_owner or has_key: print("Access granted!")

🔄The NOT Operator

The not operator reverses a boolean value. True becomes False, and False becomes True!

not
Logical NOT

Reverses True/False

# Basic NOT syntax if not condition: print("Condition is False!") # Example 1: Checking if NOT logged in is_logged_in = False if not is_logged_in: print("Please log in first") # Example 2: Account active check account_suspended = False if not account_suspended: print("Account is active") # Example 3: Checking age (NOT a minor) age = 25 is_minor = age < 18 if not is_minor: print("Adult access granted") # NOT with comparisons username = "guest" if not username == "admin": print("Limited access")

🔗Combining Multiple Operators

The real power comes when you combine and, or, and not together!

# Example 1: Complex login system username = "admin" password = "secret" is_active = True is_banned = False if username == "admin" and password == "secret" and is_active and not is_banned: print("✅ Login successful!") else: print("❌ Login failed!") # Example 2: Ticket pricing age = 15 is_student = True is_weekend = True if (age < 18 or is_student) and not is_weekend: print("Discount available!") # Example 3: Access control is_admin = False is_moderator = True has_permission = True is_verified = True if (is_admin or is_moderator) and has_permission and is_verified: print("Full access granted!")

⚠️Order of Operations!

Python evaluates logical operators in this order:

  1. not (highest priority)
  2. and (medium priority)
  3. or (lowest priority)

Use parentheses ( ) to make your logic clear!

# Without parentheses - confusing! if a or b and c: # Which is evaluated first? # With parentheses - clear! if a or (b and c): # Much better! if (a or b) and c: # Different meaning!
