What are Variables?

Think of variables as labeled storage boxes where you can keep different types of information! Just like you might have a box labeled "Toys" or "Books", in programming we create boxes (variables) to store data.

💡Key Idea

A variable is like a container that holds a value. You give it a name, and Python remembers what's inside!

Creating Variables in Python

Creating a variable is super easy! You just need three things:

  1. Variable name (what you call your box)
  2. Equal sign = (this stores the value)
  3. Value (what you put in the box)
name = "Alex" age = 12 favorite_game = "Minecraft" score = 95 is_student = True

Variable Naming Rules & Conventions

Just like you can't name your pet anything (like "123Dog" or "My Pet!"), variables have rules too!

✅DO's (Good Names):

  • Start with a letter or underscore: name, _count
  • Use letters, numbers, and underscores: player_score, level2
  • Use lowercase with underscores: favorite_color
  • Make names meaningful: student_age (not sa)

❌DON'Ts (Bad Names):

  • Start with a number: 2cool ❌
  • Use spaces: my name ❌
  • Use special characters: score!, name@ ❌
  • Use Python keywords: print, if, for ❌
