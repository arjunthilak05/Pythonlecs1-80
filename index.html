📚 Lectures 16-17 — Dictionaries

What is a Dictionary?

A dictionary is a collection that stores data as key-value pairs — like a real dictionary where you look up a word (key) to find its definition (value). Instead of accessing items by position (like lists), you access them by name!

# Creating a dictionary student = { "name": "Alice", "age": 14, "grade": "8th", "gpa": 3.8 } # Access by key (not index!) print(student["name"]) # Alice print(student["gpa"]) # 3.8 # Lists use numbers, Dictionaries use keys fruits_list = ["apple", "banana"] # access: fruits_list[0] fruit_prices = {"apple": 1.50, "banana": 0.80} # access: fruit_prices["apple"]
💡 Think of dictionaries like contacts in your phone — you look up a person's name (key) to get their phone number (value)!

Creating Dictionaries

Use curly braces { } with key: value pairs separated by commas:

# Empty dictionary empty_dict = {} # String keys with different value types person = { "name": "Bob", "age": 15, "hobbies": ["coding", "gaming"], "is_student": True } # Numbers can be keys too! scores = { 1: "Alice", 2: "Bob", 3: "Charlie" } # Using dict() constructor colors = dict(red="#FF0000", blue="#0000FF", green="#00FF00")

Accessing & Modifying Dictionary Data

Access values using keys in square brackets, or use .get() to avoid errors:

# Dictionary of a game character character = { "name": "Hero", "health": 100, "level": 5 } # Access with brackets print(character["name"]) # Hero # Modify existing key character["health"] = 90 character["level"] = 6 # Add new key-value pair character["weapon"] = "Sword" character["gold"] = 250 # .get() method - returns None if key doesn't exist (no error!) print(character.get("name")) # Hero print(character.get("mana")) # None (instead of error) print(character.get("mana", 0)) # 0 (default value)
💡 Use .get() when you're not sure if a key exists — it won't crash your program!

Dictionary Methods

Dictionaries have powerful built-in methods:

student = {"name": "Alice", "age": 14, "grade": "A"} # .keys() - get all keys print(student.keys()) # dict_keys(['name', 'age', 'grade']) # .values() - get all values print(student.values()) # dict_values(['Alice', 14, 'A']) # .items() - get key-value pairs print(student.items()) # dict_items([('name', 'Alice'), ('age', 14)...]) # .pop() - remove and return value age = student.pop("age") # Returns 14, removes "age" key print(age) # 14 # .update() - add/update multiple items student.update({"gpa": 3.9, "grade": "A+"}) # .clear() - remove all items student.clear() # Now empty: {} # in - check if key exists if "name" in student: print("Name found!")

Looping Through Dictionaries

Iterate through keys, values, or both:

grades = {"Math": 95, "Science": 88, "English": 92} # Loop through keys (default) for subject in grades: print(subject) # Math, Science, English # Loop through keys explicitly for subject in grades.keys(): print(subject) # Loop through values for score in grades.values(): print(score) # 95, 88, 92 # Loop through key-value pairs (most common!) for subject, score in grades.items(): print(f"{subject}: {score}") # Math: 95 # Science: 88 # English: 92

When to Use Dictionaries vs Lists

📚 Dictionaries

Use when:

  • Data has labels/names
  • Need fast lookup by key
  • Order doesn't matter much
  • Example: student records, settings, database entries
📋 Lists

Use when:

  • Data is ordered sequence
  • Access by position (index)
  • Order is important
  • Example: steps, scores, items in order
# LIST - ordered sequence of items scores = [95, 88, 92, 85] print(scores[0]) # 95 # DICTIONARY - labeled data student = {"name": "Alice", "math": 95, "science": 88} print(student["math"]) # 95

📦 Lecture 18 — Tuples

What is a Tuple?

A tuple is like a list, but immutable — once you create it, you can't change it! Use tuples when you want data that should never be modified.

# Creating tuples - use parentheses ( ) coordinates = (10, 20) rgb_color = (255, 128, 0) person = ("Alice", 14, "8th grade") # Single item tuple - need trailing comma! single = (42,) # Tuple with one item not_tuple = (42) # This is just a number! # Empty tuple empty = () # Accessing like lists - by index print(coordinates[0]) # 10 print(person[1]) # 14 # But you CAN'T modify! # coordinates[0] = 15 # ERROR! Tuples are immutable!
💡 Think of tuples as locked lists — you can read the data, but you can never change it!

Why Use Tuples?

Tuples are faster and safer than lists when data shouldn't change:

📦 Tuples
  • ✅ Immutable (can't change)
  • ✅ Faster than lists
  • ✅ Can be dictionary keys
  • ✅ Safe for constants
ORIGIN = (0, 0) days = ("Mon","Tue","Wed")
📋 Lists
  • ✅ Mutable (can change)
  • ⚡ Slightly slower
  • ❌ Can't be dict keys
  • ✅ For changing data
scores = [95, 88, 92] scores.append(85)

Tuple Operations

You can't modify tuples, but you can read and combine them:

# Unpacking - assign tuple values to variables point = (100, 200) x, y = point print(x) # 100 print(y) # 200 # Multiple assignment (uses tuples internally!) name, age, grade = "Alice", 14, "8th" # Tuple methods (only 2!) numbers = (1, 2, 3, 2, 2, 4) print(numbers.count(2)) # 3 (appears 3 times) print(numbers.index(3)) # 2 (at index 2) # Concatenation - creates NEW tuple a = (1, 2) b = (3, 4) c = a + b # (1, 2, 3, 4) # Length and membership print(len(point)) # 2 print(100 in point) # True

When to Use Tuples

  • 📍 Coordinates: (latitude, longitude) or (x, y)
  • 🎨 RGB Colors: (255, 128, 0)
  • 📅 Dates: (2024, 12, 25)
  • 🔑 Dictionary keys: Can use tuples, not lists!
  • 📦 Returning multiple values from functions
  • 🔒 Constants that should never change
# Tuples as dictionary keys locations = { (40.7128, -74.0060): "New York", (51.5074, -0.1278): "London" } # Return multiple values (creates tuple) def get_stats(): return 95, 88, 92, 90 # Returns tuple avg, high, low, count = get_stats() # Unpacking
🎯 Lecture 18 — Sets

What is a Set?

A set is an unordered collection of unique items — no duplicates allowed! Perfect for removing duplicates or checking membership.

# Creating sets - use curly braces or set() colors = {"red", "blue", "green"} numbers = {1, 2, 3, 4, 5} # Duplicates are automatically removed! duplicates = {1, 2, 2, 3, 3, 3, 4} print(duplicates) # {1, 2, 3, 4} # Convert list to set (removes duplicates) numbers_list = [1, 2, 2, 3, 3, 3, 4, 4] unique = set(numbers_list) print(unique) # {1, 2, 3, 4} # Empty set - MUST use set(), not {} empty = set() # Correct wrong = {} # This is an empty dictionary!
💡 Sets are like bags of unique items — you can't have two of the same thing!

Set Operations

Sets have powerful mathematical operations:

a = {1, 2, 3, 4} b = {3, 4, 5, 6} # Add items a.add(5) # {1, 2, 3, 4, 5} # Remove items a.remove(5) # Removes 5 (error if not found) a.discard(10) # Removes if exists (no error) # Membership (very fast!) print(3 in a) # True # Length print(len(a)) # 4 # Clear all # a.clear() # Empty set

Set Mathematical Operations

Sets support union, intersection, difference — like Venn diagrams!

a = {1, 2, 3, 4} b = {3, 4, 5, 6} # UNION (|) - all items from both sets print(a | b) # {1, 2, 3, 4, 5, 6} print(a.union(b)) # Same thing # INTERSECTION (&) - items in BOTH sets print(a & b) # {3, 4} print(a.intersection(b)) # DIFFERENCE (-) - items in A but NOT in B print(a - b) # {1, 2} print(a.difference(b)) # SYMMETRIC DIFFERENCE (^) - items in A or B, but NOT both print(a ^ b) # {1, 2, 5, 6} print(a.symmetric_difference(b)) # SUBSET/SUPERSET checks small = {1, 2} print(small.issubset(a)) # True (all items of small are in a) print(a.issuperset(small)) # True (a contains all of small)

When to Use Sets

  • 🗑️ Remove duplicates from a list
  • ⚡ Fast membership testing (faster than lists!)
  • 🔢 Mathematical operations (union, intersection)
  • 🎯 Track unique items (unique visitors, tags)
🎯 Sets
  • ✅ Unique items only
  • ✅ Super fast lookup
  • ❌ No order, no index
  • ❌ Can't have duplicates
📋 Lists
  • ✅ Allows duplicates
  • ✅ Ordered by index
  • ⚡ Slower lookup
  • ✅ Can modify items

  • Duplicates: No (unique only)
  • Access: No index
  • Use: Unique items
